# TradeMind Education — План развития

## Анализ Investopedia Simulator (референс)

Investopedia Stock Simulator — золотой стандарт образовательных трейдинг-платформ:
- **$100,000 виртуальных денег** — стартовый баланс
- **Реальные рыночные данные** (15-мин задержка)
- **Типы ордеров**: Market, Limit, Stop-Loss, Stop-Limit, Trailing Stop
- **Портфель**: текущая стоимость, P&L, распределение по секторам
- **Торговый журнал**: заметки к каждой сделке
- **Лидерборд**: рейтинг пользователей
- **Аналитика**: Sharpe ratio, max drawdown, beta
- **Образование**: встроенные статьи и туториалы
- **Алерты**: уведомления о ценах

## Архитектура (текущая)

```
src/
├── app/
│   ├── layout.tsx          # Root layout
│   ├── page.tsx            # Main page with tabs
│   ├── globals.css         # Global styles
│   └── api/route.ts        # Server API
├── components/
│   ├── Achievements.tsx    # Achievements tab
│   ├── LessonList.tsx      # Learning tab
│   ├── MentorPanel.tsx     # Rule-based mentor
│   ├── Simulator.tsx       # Trading simulator
│   ├── UserStats.tsx       # User statistics
│   └── WalletConnect.tsx   # Phantom wallet
├── data/
│   ├── lessons.ts          # Lesson data
│   └── scenarios.ts        # Trading scenarios
└── lib/
    ├── mentor.ts           # Trade analysis
    ├── phantom.ts          # Phantom wallet
    ├── supabase.ts         # Supabase client
    └── types.ts            # TypeScript types
```
