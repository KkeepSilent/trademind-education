# TradeMind Education

Образовательная платформа для обучения трейдингу на криптовалютах.

## Возможности

- 🎓 **Обучение** — 4 учебных модуля по основам трейдинга
- 📈 **Симулятор** — торговля BTC, ETH, SOL с реальными ценами
- 🏆 **Достижения** — 12 достижений за активность
- 👛 **Phantom** — интеграция с Solana Devnet
- 💾 **Supabase** — сохранение прогресса и сделок
- 📊 **Аналитика** — P&L, винрейт, статистика

## Быстрый старт

```bash
# Установка
npm install

# Настройка
cp .env.example .env.local
# Заполните .env.local ключами Supabase

# Запуск
npm run dev
```

Откройте http://localhost:3000
